# Owen Miele's Home Lab

A virtualized cybersecurity lab built with Proxmox VE, Wazuh SIEM, Windows Server 2025, Active Directory, Ubuntu Server, and a Windows 11 endpoint.

![Cybersecurity Home Lab Architecture](Images/Architecture_graph.png)

## Project Overview

This lab provides hands-on experience with virtualization, centralized security monitoring, Windows administration, endpoint telemetry, networking, and incident analysis.
