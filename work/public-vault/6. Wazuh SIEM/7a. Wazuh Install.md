Install Wazuh dashboard, server, and indexer on the virtual Ubuntu server

## Prerequisites

- Proxmox
- Ubuntu Server

# Procedure

1. Ensure the Ubuntu box has been updated

2. curl -sO https://packages.wazuh.com/4.14/wazuh-install.sh
sudo bash wazuh-install.sh -a

3. Make sure you save the username and password that are given after the installation

4. Utilize https://insert ip:443 to open your dashboard

5.  Run sudo systemctl status wazuh-manager --no-pager
    sudo systemctl status wazuh-indexer --no-pager
    sudo systemctl status wazuh-dashboard --no-pager
    
    ![Wazuh Dashboard Working|589](../Images/Wazuh_Working.png)

6. Ensure that all services are running
